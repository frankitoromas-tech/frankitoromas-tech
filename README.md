- 🤖 **IA, Automatización & Tools:** Desarrollo asistido por IA (**AI-Assisted Dev / Vibe Coding**), integración de herramientas **Model Context Protocol (MCP)**, scripts de automatización en **Python**, control de versiones con **Git & GitHub** y entornos **Linux (Bash CLI)**.
